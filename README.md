# American-Option-Experiment
An European option calculator fixed with both an American Option calculator using CRR and an experimental idea which splits the American option into multiple European options and using gradient ascent finds the maximum. 


This code is an experiment done testing the difference between American Options and European Options split up into small pieces. The idea is trying to approximate American Options by splitting the choice to sell into many European Options and finding the maximum point where selling was best. To do this,
I first wrote the code to generate the cost of a European Option by simply applying the formulas. Then I used code on how American Options are normally done with CRR and applied that in my project. Finally, the experimental part (which I call the Theta American Method): I split the American option into multiple pieces (called time_steps) and then performed gradient ascent on every single one of them. Then, by finding the maximum of the gradient ascents, I would in theory find a good approximation of the global maximum. Then I put this idea to the test by changing some variables and checking how long it took to run and placing them into figures.

Each figure tests both Put options and Call options as call options for American and European options give more similar results compared to put options. Then, figures 1-4 calculate differences in relative percentages between the new Theta American Method and the American option. The thought process was that the Theta American Method acts quite like the European option and therefore, the best places to test differences is when the European option would fail to approximate the American option. These independent variables are what were chosen for Figures 1-4. Then for figure 5, it is a simple runtime checker. Note that time steps for CRR (the normal American method) are much quicker than the Theta American Method and therefore, running the same number of time steps for both makes the Theta American Method look a lot slower (but the Theta American Method converges much faster). 

As we can see from the plots, sometimes the Theta American Option did approximate the American option well. As expected, usually the Put option would do worse than the call option. For most experiments it does not seem to be a very accurate indicator which implies that the Theta American Method gives very different results compared to the tried and true CRR method for calculating the American option.
